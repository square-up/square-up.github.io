单调栈

常见使用场景

在 $ O(n) $ 时间内求解一类求一个数列中每一个数左 / 右第一个比自身大 / 小的数

实现策略

以寻找右边第一个比自己大的数为例：

栈内存储的是所有尚未找到对应更大的数的元素，显然保持单调递减。

逐个对整个数列中的元素进行扫描，扫描到新元素num[i]的时候，开始和单调栈中的栈顶元素进行比较，看看是否能进行更新

  1. 若num[i] > num[栈顶]，则栈顶元素已找到对应右边第一个更大的数，将栈顶元素出栈
  2. 重复进行该操作，直到 num[i] <= num[栈顶] 或栈空
  3. 将 i 压入栈中

例题及相关题解

接雨水

这题也是单调栈的经典用法，不过这里先不展开。它和后面的柱状图最大矩形有一点共同直觉：遇到一个“边界”时，才知道中间某些位置可以结算。

护林员盖房子

题目地址：http://cs101.OpenJudge.cn/practice/27205

类似：LeetCode 85 最大矩形

题目概述

描述

在一片保护林中，护林员想要盖一座房子来居住，但他不能砍伐任何树木。现在请你帮他计算：保护林中所能用来盖房子的矩形空地的最大面积。

输入

保护林用一个二维矩阵来表示，长宽都不超过 1000（即<=1000）。
第一行是两个正整数 m,n，表示矩阵有 m 行 n 列。
然后是 m 行，每行 n 个整数，用 1 代表树木，用 0 表示空地。

输出

一个正整数，表示保护林中能用来盖房子的最大矩形空地面积。

思路分析

显然可以进行预处理，我们可以得到每个 0 在一列内后面接了几个连续的 0

对于 1000 * 1000 的地图，显然已经无法暴力枚举左上角 + 右下角并且暴力判断，我们考虑枚举矩形的上边界，由于已经预处理出每个零在一行内后面接了几个连续的 0，我们以列坐标为横轴，连续的 0 的个数为纵轴，我们可以得到一个柱状图，而以该行为上边界的最大 0 矩阵的求解就转化为柱状图中最大矩形的求解，利用单调栈在 $O(cols)$ 时间内容易实现

时间复杂度：$O(rows * cols)$

柱状图中最大矩形

当我们在执行单调栈的时候，一个元素被出栈的时候即可计算 以该元素对应的柱子为矩形高时的矩形面积

若该元素 i 被元素 j 弹出栈，则意味着 j 是 i 的右边第一个比 i 低的柱子；而若将 i 弹出后栈非空，下一个栈顶 k 即为 i 左边第一个比 i 低的柱子；若弹出 i 后栈空，说明 i 左边的柱子高度均不低于 i, k = 0

故 area[i] = height[i] * (j - k - 1)

一个小 tips：为了方便把所有元素都出栈，可以在柱状图最后放一个高度为 -1 的柱子
