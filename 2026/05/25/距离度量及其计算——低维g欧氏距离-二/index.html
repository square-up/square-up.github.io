WSPD 计算最小生成树

最小生成树的基本算法

并查集

应用：动态维护集合的连通性（哪些点已经在同一个连通块中）。

主要分为两个步骤

  1. find(x) 查询 x 在哪个集合中（返回集合的代表点）
  2. unite(x, y) 将 x, y 所在集合进行合并

初始化：所有点都在单独的集合，代表点都是自己 fa[i] = i

代码实现

优化：

  1. 路径压缩 通过 find(x)递归找到根后，直接把 x 连接到根上，可以写作 return fa[x] = find(fa[x])
  2. 按大小合并 把小集合合并到大集合中，需要额外维护集合内的点数 size（注意随着合并的进行，只有代表点存储的 size 是准确的）。

Kruskal 算法

Kruskal 的思路非常朴素：把所有边按权值从小到大排序，依次尝试加入当前答案。如果这条边连接的是两个不同连通块，就加入；如果已经在同一个连通块里，加入它只会成环，直接跳过。

在普通图上，瓶颈主要是排序；在低维几何图里，真正麻烦的是边数太多，所以后面才会引出 WSPD：希望不用真的枚举所有点对边，也能找到足够支撑 MST 的候选边。
