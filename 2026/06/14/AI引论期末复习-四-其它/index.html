5. 本题关键理解

5.1 透视投影和正交投影的区别

透视投影：

  • 射线从相机点 出发；
  • 不同像素对应不同方向；
  • 有近大远小效果；
  • 更接近真实相机和人眼。

正交投影：

  • 射线从屏幕像素点出发；
  • 所有射线方向相同；
  • 物体大小与距离无关；
  • 常用于 CAD、工程图、三视图。

一句话记忆：

透视投影：从相机点发散出去。
正交投影：从屏幕平行射出去。

6.4 几何获取

几何获取：把真实世界中的物体转成数字几何模型。

时差测距 Time of Flight

思想：

  • 发出光信号；
  • 测量反射回来的时间；
  • 根据时间计算距离。

常见于：

  • 深度相机；
  • 激光雷达。

结构光 Structured Light

思想：

  • 向物体投射已知图案；
  • 用相机观察图案变形；
  • 根据变形恢复三维形状。

常见图案：

  • 条纹；
  • 点阵；
  • 网格。

立体视觉 Stereoscopic Vision

思想：

  • 用两个或多个相机从不同角度拍摄；
  • 匹配不同图像中的对应点；
  • 根据视差恢复深度。

类似人类双眼通过视差感知距离。

几何获取流程

真实物体
→ 传感器采集
→ 点云
→ 几何重建
→ 网格 / SDF / 其他表示

7. 绘制 Rendering

7.1 绘制的定义

绘制就是把三维几何模型转换成二维图像。

核心问题：

  1. 每个像素看到哪个物体？
  2. 这个物体在该位置是什么颜色？

对应到光线追踪：

  1. 射线与哪个物体相交？
  2. 交点处如何着色？

7.3 绘制的两个目标

真实感

希望生成的图像接近真实照片。

需要考虑：

  • 光照；
  • 阴影；
  • 反射；
  • 折射；
  • 材质；
  • 全局光照。

速度

希望绘制足够快。

典型需求：

  • 游戏；
  • 交互式系统；
  • 实时仿真；
  • 虚拟现实。

真实感和速度通常需要权衡。

8. 光栅化 Rasterization

8.1 基本思想

光栅化：

把三维物体投影到二维屏幕，
再判断它覆盖哪些像素，
给这些像素填充颜色。

8.2 基本流程

初始化图像为背景颜色
→ 遍历场景中的物体
→ 将物体投影到屏幕
→ 光栅化成像素
→ 计算像素颜色
→ 处理遮挡关系

8.3 特点

优点：

  • 速度快；
  • 适合实时渲染；
  • GPU 支持成熟；
  • 游戏和交互应用中常用。

缺点：

  • 复杂光照处理不自然；
  • 反射、折射、全局光照需要额外技巧。

9. 光线追踪 Ray Tracing

9.1 基本思想

光线追踪：

从相机或屏幕像素发出射线，
看射线打到哪个物体，
再计算交点颜色。

9.2 基本流程

遍历每一个像素
→ 构造该像素对应的射线
→ 判断射线与场景中物体是否相交
→ 若不相交，返回背景色
→ 若相交，取最近交点
→ 计算交点颜色

9.3 光线追踪中的两类计算

几何计算

问题：

  • 射线是否与物体相交？
  • 交点在哪里？
  • 哪个交点离相机最近？

着色计算

问题：

  • 交点处的法向量是什么？
  • 光源方向是什么？
  • 材质如何反射光？
  • 最终颜色是多少？

9.4 特点

优点：

  • 物理直觉清楚；
  • 适合高真实感渲染；
  • 反射、折射、阴影更自然。

缺点：

  • 计算量大；
  • 通常比光栅化慢；
  • 实时渲染需要硬件加速或近似。

9.5 光栅化与光线追踪对比

方法 思路 优点 缺点
光栅化 物体找像素 快，适合实时 复杂光影不自然
光线追踪 像素找物体 真实感强 计算量大

记忆：

光栅化：物体投到屏幕上。
光线追踪：从像素往场景里看。

14. 反射、折射与全局光照

14.1 反射

当射线打到镜面物体时，会沿反射方向继续传播。

光线追踪可以递归追踪反射光线。

14.2 折射

当射线进入玻璃、水等透明介质时，方向会改变。

这对应折射现象。

14.3 全局光照

全局光照考虑：

  • 光源直接照射物体；
  • 物体反射出的光继续照亮其他物体；
  • 多次反射共同决定最终颜色。

特点：

  • 真实感强；
  • 计算量大。

15. 神经辐射场 NeRF

15.1 传统绘制思路

传统光线追踪：

明确几何模型
→ 射线与几何模型求交
→ 在交点处计算颜色

15.2 NeRF 思路

NeRF 使用神经网络表示三维场景。

大致流程：

从像素发出射线
→ 沿射线采样许多空间点
→ 神经网络预测每个点的颜色和密度
→ 按透明度累积颜色
→ 得到像素颜色

15.3 NeRF 的特点

  • 用神经网络隐式表示三维场景；
  • 同时表达几何和外观；
  • 可以根据已有多视角图像生成新视角图像；
  • 属于神经隐式表示的一类。

17. 最简答题模板

17.1 光线追踪如何计算像素颜色？

可以答：

对每个像素构造一条射线；
判断射线是否与场景中的物体相交；
若不相交，则返回背景颜色；
若相交，则取最近交点；
计算交点处的法向量和光照方向；
使用着色模型，如朗伯模型，计算像素颜色。

17.2 透视投影和正交投影的区别？

可以答：

透视投影中，射线从相机点出发，穿过屏幕像素，
不同像素对应不同方向，因此有近大远小效果。
正交投影中，所有射线互相平行，
物体大小与距离无关，常用于工程图和 CAD。

17.3 隐式表示和显式表示的区别？

可以答：

隐式表示用方程 f(x,y,z)=0 定义形状，
判断点与形状关系方便，但枚举表面点困难。
显式表示直接给出表面点的生成方式，
枚举表面点方便，但判断点与形状关系困难。
