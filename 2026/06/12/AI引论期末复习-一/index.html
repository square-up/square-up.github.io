句法分析：CYK 算法

上下文无关文法（CFG）

  1. 终结符
  2. 非终结符
  3. 起始符号
  4. 产生式规则

输入文法格式：乔姆斯基范式（CNF）

  1. 一个非终结符推出两个非终结符
  2. 一个非终结符推出一个终结符

普通规则转成乔姆斯基范式：

  1. 右边超过两个符号：引入新的非终结符并多加规则，拆成二叉结构
  2. 终结符出现在右边：为它单独造一个非终结符

具体算法步骤

三个特点：自底向上；动态规划；三角形表格

表格中格子含义：X(i, j) = 能够推出子串 的所有非终结符集合

输入

  • CNF 文法 G
  • 字符串 w = w1 w2 ... wn

输出

  • 判断 w 是否属于 L(G)

步骤

  1. 构造三角形表格 X。
  2. 对每个单词 wi，根据 A → wi 填入 X(i,i)。
  3. 按照子串长度从 2 到 n 依次填表。
  4. 对每个子串 wi...wj，枚举切分点 k。
  5. 若存在 A → B C，且 B ∈ X(i,k), C ∈ X(k+1,j)，则 A ∈ X(i,j)。
  6. 最后检查 S 是否属于 X(1,n)。

统计语言模型与词表示

统计语言模型关心的是“一个句子出现的概率有多大”。从 n-gram 到词向量，思路大致是从离散计数走向连续表示：前者好算但表达能力有限，后者能把词语放进向量空间里，让相似词在几何上也更接近。

Transformer 复习提纲：从 RNN 到大语言模型

整体主线：
自然语言是序列 → RNN 处理序列 → RNN 有长距离依赖和并行问题 → Attention 缓解信息瓶颈 → Self-Attention 让 token 直接互相看 → Transformer 用多头注意力、位置编码、残差连接、LayerNorm、FFN 组成完整结构 → Decoder 通过 Linear + Softmax 预测下一个 token → 大语言模型是 Transformer 的大规模扩展。

一、从 RNN 到 Attention：为什么需要 Transformer

1. 自然语言是序列问题

自然语言处理中的文本不是孤立的词集合，而是有顺序的 token 序列。

例如：

我 喜欢 你

和：

你 喜欢 我

包含的词一样，但顺序不同，含义完全不同。

常见 NLP 任务包括：

  • 文本分类：句子 → 类别
  • 机器翻译：源语言序列 → 目标语言序列
  • 文本生成：前文 → 后文
  • 问答：问题 + 上下文 → 答案
  • 摘要：长文本 → 短文本

因此，模型需要处理：

  • 序列顺序；
  • 上下文依赖；
  • 不定长输入；
  • 不定长输出。

3. RNN 的优缺点

RNN 的优点：

  • 可以处理任意长度的序列；
  • 输入长度变化时，模型参数量不变；
  • 适合处理文本、时间序列等顺序数据。

RNN 的缺点：

3.1 难以并行

因为：

所以必须先算 ，才能算 。

也就是说：

h1 → h2 → h3 → h4 → ...

不能像矩阵运算那样一次性并行计算所有位置。

3.2 长距离依赖困难

例如：

The course which seems very difficult is fun.

主语 course 和形容词 fun 隔得很远。

RNN 需要通过隐藏状态一步步传递信息，经过很多次更新后，前面的信息可能被冲淡或遗忘。

这会导致：

  • 梯度消失；
  • 长距离依赖难以捕获；
  • 早期信息容易丢失。

Attention 的作用是缓解 RNN seq2seq 的信息瓶颈。

Encoder 把所有位置的隐藏状态都传给 Decoder
Decoder 每一步生成时，对所有隐藏状态分配不同权重

二、Self-Attention：Transformer 的核心机制

1. 从 Attention 到 Self-Attention

普通 Encoder-Decoder Attention 是：

Decoder 的 token 去看 Encoder 的 token

Self-Attention 是：

同一个序列内部，每个 token 去看这个序列里的其他 token

例如句子：

The animal didn't cross the street because it was tired.

当模型处理 it 时，需要知道它可能指代 animal。

RNN 要靠隐藏状态一步步传递，而 Self-Attention 可以让 it 直接关注 animal。

核心思想：

每个 token 都可以直接和所有 token 建立联系，从上下文中吸收自己需要的信息。

每个 token 原本有一个表示向量：

  • Query：我想找什么信息？
  • Key：我有什么特征，别人能不能找到我？
  • Value：如果别人关注我，我真正传递什么信息？

注意：

Q、K、V 不是三个不同的词，而是同一个 token 表示通过三套矩阵投影出来的中间变量。

可以类比成查资料：

  • Query：你提出的问题；
  • Key：资料的标签；
  • Value：资料的正文内容。

Attention 做的事情就是：

用 Query 匹配所有 Key
↓
得到相关性权重
↓
按权重读取所有 Value

5. Q/K/V 更新的是自己吗

严格来说，一个 token 更新的不是自己的 Q、K、V，而是自己的 hidden representation。

在某一层中：

当前 token 表示 x_i
↓
临时算出 q_i, k_i, v_i
↓
用 q_i 匹配所有 k_j
↓
对所有 v_j 加权求和
↓
得到新的 token 表示 o_i

Q/K/V 是当前层中的中间变量。

到了下一层，会根据新的 token 表示重新计算新的 Q/K/V。

所以可以记成：

更新的是 token 表示；Q/K/V 是由当前 token 表示临时投影出来的计算工具。

6. QKV 矩阵怎么训练

和神经网络里的其他参数一样，都是通过反向传播和梯度下降训练出来的。

训练过程：

输入文本
↓
前向传播
↓
计算 Q/K/V
↓
计算 attention
↓
预测下一个 token 或完成其他任务
↓
计算 loss
↓
反向传播
↓
更新 WQ, WK, WV 等参数

一开始 Q/K/V 矩阵是随机的。

训练之后，模型逐渐学会：

  • 什么样的 query 应该匹配什么样的 key；
  • 哪些 value 信息应该被传递；
  • 不同 head 应该关注不同类型的关系。

这就是为什么 Transformer 看起来“神奇”：
人没有显式写语法规则，而是设计了结构和训练目标，让模型从数据中学出隐含规律。

2. Masked Self-Attention：不能偷看未来

Decoder 是自回归生成的，不能偷看未来 token。

普通 self-attention：

每个位置可以看所有位置

Masked self-attention：

第 t 个位置只能看第 1 到第 t 个位置
不能看未来位置

例如目标序列：

允许关注关系：

y1: y1
y2: y1, y2
y3: y1, y2, y3
y4: y1, y2, y3, y4

原始 Transformer 是 Encoder-Decoder 架构：

输入序列
↓

↓
Encoder 输出

目标序列

    - Masked Self-Attention
    - Cross-Attention
    - Feed Forward
↓

↓
Softmax
↓

Encoder：

负责理解输入序列。
Self-Attention 可以看完整输入。
输出输入序列每个 token 的上下文化表示。

Decoder：

负责逐步生成输出序列。
Masked Self-Attention 只能看过去，不能看未来。
Cross-Attention 可以看 Encoder 输出。
最终通过 Linear + Softmax 预测下一个 token。

六、Transformer 与大语言模型

1. 大语言模型是什么

大语言模型可以粗略理解为：

基于 Transformer 架构的大规模语言模型

核心训练目标常常是：

给定前文，预测下一个 token

即：

当模型足够大、数据足够多时，预测下一个 token 的过程中会学到大量语言规律、知识和任务模式。

2. 常见 Transformer 变体

常见结构：

BERT：encoder-only
GPT：decoder-only
T5 / 原始 Transformer：encoder-decoder

BERT：

主要使用 Encoder。
可以双向看上下文。
适合理解类任务，如文本分类、阅读理解、句子匹配等。

GPT：

主要使用 Decoder。
使用 masked self-attention，只能看前文。
适合生成类任务，如续写、对话、问答、代码生成等。

T5 / 原始 Transformer：

使用 Encoder-Decoder。
适合机器翻译、摘要、改写等 seq2seq 任务。

3. 为什么 GPT 只用 Decoder 也能对话

对话可以被转化成续写任务。

例如输入：

用户：Transformer 是什么？
助手：

GPT 的任务就是继续生成：

Transformer 是一种基于注意力机制的神经网络架构……

所以 GPT 的核心过程是：

根据已有上下文预测下一个 token
↓
把预测出的 token 接到后面
↓
继续预测下一个 token
↓
不断重复，直到生成结束

本质仍然是自回归语言模型。

七、最终总结

1. 整体逻辑链

自然语言是序列
↓
RNN 可以处理序列
↓
RNN 用 hidden state 逐步传递信息
↓
RNN 的问题：难并行、长距离依赖差、信息瓶颈
↓
seq2seq 使用 Encoder-Decoder 处理输入序列到输出序列
↓
Attention 让 Decoder 每一步都能动态关注 Encoder 的所有 hidden states
↓
Self-Attention 让同一序列内部的 token 彼此关注
↓
Q/K/V 让 token 学会“找信息、被匹配、传信息”
↓
Scaled Dot-Product Attention 用矩阵并行计算所有 token 的关系
↓
Multi-Head Attention 从多个角度建模 token 关系
↓
Positional Encoding 补充顺序信息
↓
Residual + LayerNorm 稳定深层训练
↓
FFN 对每个 token 表示做非线性加工
↓
Encoder 负责理解输入
↓
Decoder 负责在不偷看未来的情况下逐步生成
↓
Linear + Softmax 把隐藏表示转成词表概率
↓
大语言模型是 Transformer 的大规模扩展

3. 一句话总结

Transformer 的核心思想是：

不再像 RNN 那样把信息一步步传下去，而是让每个 token 通过 self-attention 直接和所有 token 建立联系，再通过多头注意力、位置编码、残差连接、LayerNorm、FFN 和多层堆叠，形成强大的上下文表示；最后 Decoder 通过自回归方式不断预测下一个 token。
